# HCP Lifespan (Aging + Development)

The HCP Lifespan studies extend the original HCP Young Adult protocol across the human lifespan. HCP-Aging (HCP-A) is enrolling 1200+ adults 36-100+ years; HCP-Development (HCP-D) is enrolling 1300+ youth ages 5-21. Both use a harmonized multimodal protocol covering T1, T2, diffusion, resting-state and task fMRI, and arterial spin labeling perfusion. The latest release contains 2789 sessions from 1390 participants, totaling approximately 42 TB. Twin and longitudinal subsamples exist in HCP-D.

## Access and tier

Registration. Sign HCP Lifespan Open Access Data Use Terms; data hosted via NDA collection 2847 and ConnectomeDB.

## Format and download

Native: NIfTI/CIFTI. Recommended: preprocessed minimal-pipeline outputs. NDA download via webpack; alternative AWS S3 access for some derivatives.

## Intended use for this corpus

Lifespan vision-encoder pretraining, age regression, longitudinal aging trajectories, neurodevelopmental progression. Companion to HCP1200 (young adult), extending coverage to ages 5-100+.
