# EchoNet-Synthetic

**Modality:** Ultrasound (synthetic) | **Anatomy:** Heart | **View:** A4C | **Year:** 2024

## Overview
EchoNet-Synthetic is a fully synthetic privacy-preserving echocardiogram dataset generated by a Latent Video Diffusion Model trained on Stanford EchoNet-Dynamic. Released alongside MICCAI 2024 paper by Reynaud et al. The intent is to enable open echo-video pretraining without re-distributing real patient pixels.

## Labels
Synthetic ejection fraction (EF) values are paired with each video at generation time. No real patient identifiers exist in the dataset.

## Format
AVI, similar shape to EchoNet-Dynamic (112x112, ~150 frames). Roughly 10,030 generated videos at ~7.5 GB.

## Access
Open via GitHub: https://github.com/HReynaud/EchoNet-Synthetic. Code + diffusion model weights + generated dataset are all provided. License inherited from upstream Stanford EchoNet (non-commercial research).

## Citation
Reynaud et al., "EchoNet-Synthetic: Privacy-Preserving Video Generation for Safe Medical Data Sharing." MICCAI 2024. arXiv:2406.00808.

## Notes for ingestion
- Treat as pretraining-only data; never benchmark "EF accuracy on synthetic" as a real result.
- Useful when you want a frozen encoder that has seen echo-like motion priors before fine-tuning on real EchoNet-Dynamic.
- Diffusion artifacts: occasional implausible chamber motion; consider quality filtering.
