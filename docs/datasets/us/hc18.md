# HC18 (Fetal Head Circumference Challenge)

**Modality:** Ultrasound | **Anatomy:** Fetus (head) | **View:** Trans-thalamic | **Year:** 2018

## Overview
HC18 is the long-standing Grand Challenge benchmark for automated fetal head circumference measurement. 1,334 trans-thalamic 2D ultrasound images at 800x540 pixels: 999 train / 335 test. Manual head-circumference measurements (in mm) were annotated by a trained sonographer; test labels are submitted as ellipse parameters (center, semi-axes, angle). The dataset is well-known to contain images from the same examination -- so per-patient grouping is unfortunately unavailable.

## Labels
- Head circumference in mm (training set)
- Pixel size metadata (0.052 - 0.326 mm/pixel)
- Ellipse parameter ground truth derivable from segmentation

## Format
PNG. ~38 MB total.

## Access
Registration via Grand Challenge https://hc18.grand-challenge.org/. Downloadable Zenodo deposit: https://zenodo.org/records/1322001 (DOI 10.5281/zenodo.1322001).

## Citation
van den Heuvel et al., "Automated measurement of fetal head circumference using 2D ultrasound images." *PLoS ONE* 13.8 (2018): e0200412. DOI: 10.1371/journal.pone.0200412

## Notes for ingestion
- Single-image task -- ellipse fitting / regression. No motion / video.
- Same-examination images means train/test contamination is hard to fully eliminate. Use the original challenge split as published.
- Excellent quick-validate task for any general fetal-biometry model.
