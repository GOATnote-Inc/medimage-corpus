# LLaVA-Med Instruct 60K

**Year:** 2023 (NeurIPS Spotlight) | **Paper:** [arXiv:2306.00890](https://arxiv.org/abs/2306.00890)
**Access:** open | **License:** CC-BY-NC-4.0 (research only)

## Summary

LLaVA-Med Instruct 60K is the stage-2 instruction-tuning dataset for LLaVA-Med, providing 60,000 GPT-4-generated multi-round conversational examples grounded on biomedical images. Each example references a PMC image and contains a sequence of question-answer turns (often 5+ turns) that exercise complex reasoning: figure description, comparison, differential diagnosis, scientific interpretation, and clinical context. The conversational style is a deliberate departure from one-shot VQA - LLaVA-Med pioneered conversation-based biomedical instruct-tuning as a more realistic clinical-AI training signal.

## Image modalities

Five major biomedical types: chest X-ray, CT, MRI, histopathology, gross pathology.

## Text type

Multi-round conversation traces (question-answer turns) generated by GPT-4 from PMC figure captions and surrounding paper text. Conversation lengths vary; mean ~5 turns per example.

## Size

89 MB JSON manifest; ~10 GB after downloading the 60K PMC images.

## Access

Open via the Microsoft LLaVA-Med GitHub repository. Microsoft Research License for code; CC-BY-NC-4.0 for data (non-commercial research only).

## Notes for VLM training

Stage-2 partner of `multimodal/llava_med_alignment_500k`. Use both in sequence: alignment first, then instruct-tune. The conversation format is directly compatible with LLaVA-style chat templating; the dataset is the canonical instruct-tune set for any LLaVA-Med-style biomedical VLM. Subsequent works (LLaVA-Rad, BiomedGPT, RaDialog) extend or replace this corpus with domain-specific instruction sets.
